MAT499: Introduction to Deep Learning

Spring 2026

MWF 10:20 – 11:10 am

 

Prerequisites

None. Competency in matrix algebra, calculus, and python programming is highly recommended.

 

Catalog description

Deep learning and its variants are the backbone of all modern AI technologies and advancements, yet at their core, they are just a sequence of mathematical concepts – matrices, calculus, and optimization. This course will provide students with an understanding of these mathematical foundations of deep learning, and then build on this knowledge to explore the implementation and optimization of deep learning models.

 

Course Content

The course will consist of 4 modules:

1)   Artificial Neural Networks – this section will introduce neural networks (both single-layer and multi-layer); the general fully-connected architecture, the mathematics of forward and backward propagation; learning a model from data; and the implementation of this using a major deep learning library (eg. PyTorch, Tensorflow, etc).

2)   Hyperparameter Optimization – this section will cover model depth and width; selection of loss functions, activation functions, and optimizers; training loss versus validation loss and early stopping functions; dropout and overfitting; and, the use of mini-batches for training, and the vanishing gradient problem.

3)   Convolutional Neural Networks (CNN) – this section will introduce convolutional neural networks; the mathematics of the convolution operation; analysis of convolutions learned from data; and their application to structured data such as images and time series.

4)   Recurrent Neural Networks (RNN) – this section will introduce recurrent neural networks; the mathematics of RNN layers; RNN variants including Long Short-Term Memory (LSTM) cells; and their application to sequential data including text analysis.

 

Course Structure

The class will utilize a hybrid format of lectures and project-based learning. The knowledge from each module will be reinforced by applying it to an individual project. All projects will be completed in the python programming language. Students will be required to both conceptually understand deep learning architectures as well as be able to implement these methods using their own written code.

 

Reading from various sources will be assigned to be completed at home prior to the topic being covered in class.

 

Course Learning Outcomes

Upon successful completion of this course, students will be able to:

1)   Implement a deep learning model using a common deep learning library by training it on data and using it for prediction on unseen data,

2)   Choose the most appropriate deep learning architecture for the dataset to be modeled,

3)   Explain the mathematics of a deep learning model including fully-connected models, CNNs and RNNs,

4)   Explain the bias-variance tradeoff with respect to deep learning,

5)   Troubleshoot common issues that occur in learning deep learning models, and

6)   Optimize the hyperparameters of a deep learning model.
